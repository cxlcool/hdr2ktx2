# Changelog

## v1.0 — 2026-10-13

- Initial Qt desktop app for selecting, batching, and converting HDR files to IBL-prefiltered cubemap KTX2 files.
- Bundles the native sampler, KTX runtime, shaders, Vulkan loader, and Visual C++ runtime in a one-file Windows executable.
- Adds conversion settings, overwrite protection, queue progress, logs, and KTX2 file validation.
